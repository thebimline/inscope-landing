InScope is for solo developers and PMs, PM consultancies and developers’ in-house PMs. It works best when the whole team uses it: everyone shares the same picture of the project, so the more people on it, the more value it brings.

It can be used on projects of any type and size — residential, commercial, hospitality and more — by teams including consultants and trades.

A free, lite version of InScope’s Planning Tracker, built from your planning decision notice. See what every condition needs and who’s doing it. It’s a simple way to try working in InScope. It helps you spot problems early; it doesn’t do the chasing for you.

Access and editing rights are configured for each project. Typically, internal project team members (e.g. project owners, PMs) have full visibility, while external users (e.g. contractors and consultants) see and edit information based on assignment and relevance.

InScope records who created each record and when, and who last changed its status. See the Terms of Service for revision history.

InScope is built on Airtable, a leading database and workflow platform.

Airtable is hosted on Amazon Web Services (AWS) in Europe, with customer data encrypted both in transit and at rest.

Airtable maintains high enterprise-level security and privacy standards, including compliance with SOC 2 Type 2, ISO 27001 and ISO 27701 certifications.

All project data remains the property of the user. See the Terms of Service for further details.

Clients receive a structured CSV export of their project information at project completion.

Following a short handover period, the project environment is closed.

Your project information is yours. InScope projects are run by TheBIMLine, with the data hosted by Airtable, so the service would end if we stopped trading. Before that happened, you would receive a structured export of your project information, as set out in the Terms of Service.
